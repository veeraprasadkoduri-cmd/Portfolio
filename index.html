About Me

Discover my journey, experience, and passion for DevOps and cloud technology

AWS DevOps Engineer

I'm an AWS DevOps Engineer with 3.2 years of experience helping teams ship software faster and more reliably. Most of my day-to-day work revolves around AWS Cloud, building and maintaining CI/CD pipelines in Jenkins and GitHub Actions, and provisioning infrastructure with Terraform so environments stay consistent and repeatable across Dev, QA, UAT, and Production.

On the deployment side, I containerize applications with Docker and run them on Amazon EKS, using Helm along with Rolling Update and Blue-Green strategies to roll out changes with minimal risk. I lean on Ansible for server provisioning and configuration, and I've integrated SonarQube and Trivy into pipelines to catch code quality and container vulnerability issues before they ever reach production.

I'm also the one keeping an eye on things once they're live — setting up Prometheus, Grafana, and CloudWatch dashboards and alerts, digging into incidents, doing root cause analysis, and working closely with Development, QA, Security, and Operations to keep releases smooth. I'm comfortable on Linux day to day, and I work in an Agile environment where communication and quick iteration matter just as much as the automation itself.
